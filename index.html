📋 セットアップ手順

① Googleスプレッドシートを新規作成
スプレッドシートのIDをメモしておいてください。

② Apps Script を開く
拡張機能 → Apps Script → Code.gs に同梱の Code.gs を貼り付ける。

③ SHEET_ID を設定
コードの const SHEET_ID = 'YOUR_SPREADSHEET_ID' を実際のIDに書き換える。

④ setupSheet() を実行
関数選択で setupSheet を選んで▶実行 → スプレッドシートが初期化されます。

⑤ デプロイ
デプロイ → 新しいデプロイ → 種類「ウェブアプリ」→
アクセスできるユーザー：全員 → デプロイ → URLをコピー。

⑥ 上の欄にURLを貼り付けて「保存して接続」
